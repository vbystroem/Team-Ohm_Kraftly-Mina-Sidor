# Beslut

## De tre viktigaste besluten

Vi har valt tokenlagring, rendering och grenstrategi eftersom de påverkar viktiga delar av systemets säkerhet, uppbyggnad och arbetssätt. De kan bli kostsamma att ändra och är sådant som nästa team kan vilja ifrågasätta.

1. **Tokenlagring:** Det påverkar säkerheten och användarnas inloggning. Nästa team kan vilja ifrågasätta hur tokens lagras och förnyas.
2. **Rendering – SPA:** Det påverkar hur hela applikationen är uppbyggd. Nästa team kan vilja ifrågasätta varför vi valde SPA i stället för SSR.
3. **Grenstrategi:** Det påverkar hur teamet arbetar med Git och pull requests. Nästa team kan vilja ifrågasätta varför vi valde trunk-based med squash merge.
