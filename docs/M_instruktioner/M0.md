Definition of Done

Bocka av i docs/milestones.md i ert repo:

    Teamrepo skapat från starter-templaten, med skyddad main (PR krävs + minst en godkänd review), PR-mall och CODEOWNERS
    Working agreement i README: mötestider, kommunikationsvägar, definition of done för PR:er, tech lead-schema för rotationen
    Appen körs lokalt hos alla i teamet
    Skuldinventering i docs/debt.md
    Kort logg i docs/log.md: vad ni gjorde, vad som var svårt

Så taggar ni M0

En git-tagg är ett namn på en exakt commit. Den fryser ett läge — "så här såg repot ut när vi var klara med M0" — och det är den jag tittar på när jag följer upp. Så här gör ni, när allt ovan är mergat till main:

git switch main
git pull
git tag -a M0 -m "M0 Teamet redo"
git push origin M0

Kontrollera att det gick fram: taggen ska synas under Tags på repots startsida på GitHub, eller via git ls-remote --tags origin.

Taggen flyttas inte. Kommer ni på något efteråt gör ni det i en ny PR — vi tar upp det på onsdagens avstämning. Det är hela poängen med en deadline: vi tittar på samma läge, allihop.
