    Inventera. Hitta alla knappar och allt som beter sig som en:

    grep -rn "BaseButton\|AppButton\|button-secondary\|class=\"btn\|@click" src --include="*.vue"

    // En knapp för hela appen. Utseendet väljs med variant – inte med en ny komponent.

        default: 'primary',
        validator: (value) => ['primary', 'secondary', 'text'].includes(value)

      // 'button' som standard – annars skickar varje knapp i ett formulär formuläret

    import { describe, it, expect, vi } from 'vitest'
    import { render, screen } from '@testing-library/vue'
    import userEvent from '@testing-library/user-event'
    import { axe } from 'jest-axe'
    import KButton from './KButton.vue'

    const renderButton = (props = {}, attrs = {}) =>
      render(KButton, { props, attrs, slots: { default: 'Spara ändringar' } })

    describe('KButton', () => {
      it('är en riktig knapp med texten som namn', () => {
        renderButton()

      it('går att trycka med tangentbordet (Enter och mellanslag)', async () => {

Vanliga missar – kolla innan ni taggar

    Alla axe-test gröna och klart? axe godkänner en placeholder som label, ser inte outline: none, lang="en" eller en <div @click>. Tabba igenom innan ni bockar av
    Kontrasten "kontrollerad" i Vitest → jsdom ritar ingenting och jest-axe har stängt av färgreglerna. Kontrast syns bara i Accessibility-fliken eller i browserns färgväljare
    outline: none kvar någonstans (grep -rn "outline: none\|outline:none" src) – eller en egen ring som bara syns på ljus bakgrund. Tabba genom den mörka toppmenyn också
    Samma id på två fält på en sida → båda labels pekar på det första. Skriv id för hand i vyn, inte i en komponent som används flera gånger – där behövs useId(), och det är KField i Boiler Room 3
    Ett mellanslag inuti en dold <span> försvinner – mellanslaget ska stå före <span>, annars blir namnet "Ladda nerfaktura …"
    E2E-testen letar fortfarande efter placeholdern (getByPlaceholder) och är röda i pipelinen. Byt till getByLabel
    KButton utan type="button" som standard → varje knapp i ett formulär skickar formuläret
    En ikon i en knapp läses upp som "bild" eller filnamn → aria-hidden="true" på ikonen; en knapp som bara är en ikon behöver aria-label
    KField, stories för samtliga komponenter, axe-test för varje formulärvy och Storybook i pipelinen – inte i M8. Det är Boiler Room 3 och M9
